Privacy policy

Last updated: November 9, 2026

email-screener is a personal tool used only by its developer, for the developer's own Gmail account. It has no other users.

What the app accesses

With the user's permission, the app reads unread messages in the user's Gmail account (sender, subject, and message text), reads earlier messages in the same conversation when drafting a reply, creates and applies Gmail labels, and saves reply drafts. The app never sends emails.

How the data is used

Message content is used only to rate urgency, sort messages into categories, and write suggested reply drafts for the user to review. To do this, parts of the messages are sent to the Anthropic API for processing. The data is not used for advertising, is not sold, and is not shared with anyone else.

Storage

Results are kept in files on the user's own computer. The Gmail access token is stored on the user's computer and in the user's private, encrypted GitHub secrets. The developer runs no server that collects or stores user data.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
